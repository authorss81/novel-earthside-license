Review files record a pass over finished prose and the state a batch left behind, and they record what
was repaired, what was refused and why, and what a following pass must not re-open.

**A review is not independent when the reviewer subagent is unavailable.** Several of these files were
written by the same agent kind that produced the work under review, and each says so in its first
lines rather than claiming an independence it does not have. Where a review's own instruments were
faulty, that is named in the file, because a review that reports only its agreements is a review
nobody checked.
